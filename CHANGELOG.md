# Changelog

## 1.0.0

- Adds `Procmon Events` report tab to CAPEv2.
- Server-side pagination with 25/50/100/200 rows.
- SQLite-backed index for large Procmon XML files.
- Clickable event detail modal.
- Command-line and parent-process enrichment from Procmon `processlist`.
- Recursive all-field search with field-aware syntax.
- Raw XML field display and Copy JSON / Copy path actions.
- Automatic backup, validation, and rollback installer.
- Uninstaller with optional cache cleanup.
- Optional legacy Procmon auxiliary stability patch and tested PMC profile.
